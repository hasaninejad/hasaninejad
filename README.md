# HASANINEJAD

سامانهٔ ثبت مأموریت و تردد — با تاریخ شمسی، ذخیره روی گوشی و خروجی CSV.

این مخزن دو نسخه دارد و **نسخهٔ اصلی، نسخهٔ وب (PWA)** است:

| نسخه | مسیر | وضعیت |
|---|---|---|
| **وب / PWA** (توصیه‌شده) | `docs/` | روی گوشی نصب می‌شود، آفلاین کار می‌کند، با یک کلیک روی GitHub Pages بالا می‌آید |
| Kivy (اندروید بومی) | `main.py` + `buildozer.spec` | نمونهٔ اولیه؛ برای بیلد به لینوکس و زنجیرهٔ ابزار سنگین نیاز دارد |

---

## نسخهٔ وب

### امکانات

- ثبت شروع و پایان مأموریت با تاریخ شمسی و ساعت گوشی
- محاسبهٔ خودکار مدت مأموریت
- ثبت مکان و توضیحات
- «گزارش سریع جداگانه»
- سوابق ۵۰ مأموریت آخر
- خروجی CSV با UTF-8 BOM (مستقیم در Excel باز می‌شود)
- داده‌ها فقط روی همان گوشی می‌مانند (بدون سرور، بدون حساب کاربری)
- آفلاین، قابل نصب روی صفحهٔ اصلی، رابط فارسی راست‌به‌چپ

### ۱) بالا آوردن روی GitHub Pages

1. در مخزن: **Settings** → از منوی چپ **Pages**
2. در بخش **Build and deployment**، گزینهٔ **Source** را روی **Deploy from a branch** بگذار
3. **Branch** را `main` و پوشه را **`/docs`** انتخاب کن → **Save**
4. یک تا دو دقیقه صبر کن؛ آدرس اپ این می‌شود:
   ```
   https://<username>.github.io/hasaninejad/
   ```

### ۲) نصب روی گوشی

1. همان آدرس را در **کروم** گوشی باز کن
2. منوی سه‌نقطه → **Add to Home screen** (یا **نصب برنامه**)
3. از این به بعد از آیکون روی صفحهٔ اصلی باز می‌شود، تمام‌صفحه و بدون نوار مرورگر

### ۳) گرفتن APK (اختیاری)

1. به <https://www.pwabuilder.com> برو
2. آدرس Pages را وارد کن → **Start**
3. **Package for stores** → **Android** → **Generate**
4. فایل ZIP را دانلود کن؛ داخلش `.apk` (برای نصب دستی) و `.aab` (برای Google Play) و کلید امضا هست
5. APK را روی گوشی نصب کن (اجازهٔ «نصب از منبع ناشناس» لازم است)

> APK ساخته‌شده یک **Trusted Web Activity** است: اپ در پنجرهٔ کروم باز می‌شود، پس بار اول به اینترنت نیاز دارد. خودِ اپ بعد از باز شدن، آفلاین کار می‌کند.

## ساختار پروژه

```
docs/                    ← نسخهٔ وب (همین را روی گوشی نصب می‌کنی)
├── index.html
├── styles.css
├── app.js               ← منطق اپ (ذخیره، مأموریت، CSV)
├── jalali.js            ← تبدیل تاریخ شمسی
├── manifest.webmanifest
├── sw.js                ← service worker (آفلاین)
└── icons/

tests/
├── test_dates.py        ← تست‌های نسخهٔ پایتون
└── test_jalali.js       ← تست‌های تاریخ نسخهٔ وب

scripts/
├── make_icons.py        ← ساخت آیکون‌های PWA
└── fetch_font.py        ← دانلود فونت فارسی برای نسخهٔ Kivy

main.py                  ← نسخهٔ Kivy (قدیمی)
buildozer.spec
```

## تست‌ها

```bash
# نسخهٔ پایتون (بدون نیاز به Kivy)
python -m unittest discover -s tests -v

# نسخهٔ وب (فقط Node، بدون نصب هیچ بسته‌ای)
node tests/test_jalali.js
```

هر دو مجموعه، تبدیل تاریخ شمسی را با یک پیاده‌سازی مستقل مقایسه می‌کنند و **۱۳٬۰۰۰+ روز** (۲۰۰۰ تا ۲۰۴۰) را رفت‌وبرگشت می‌زنند. این تست‌ها یک باگ واقعی را پیدا کردند: در سال‌های کبیسهٔ میلادی، تاریخ‌های بعد از اسفند یک روز جلو بودند.

## محدودیت‌ها

| مورد | توضیح |
|---|---|
| محل داده | داده در حافظهٔ مرورگر همان گوشی است. اگر «Clear site data» بزنی، پاک می‌شود — پس هر چند وقت یک‌بار **خروجی CSV** بگیر. |
| انتقال بین گوشی‌ها | خودکار نیست؛ CSV را با اشتراک‌گذاری بفرست. |
| یادآوری پس‌زمینه | پیاده نشده (نیاز به نوتیفیکیشن زمان‌بندی‌شده). |
| iOS | نصب روی صفحهٔ اصلی کار می‌کند، ولی محدودیت‌های سافاری اعمال می‌شود. |

## نسخهٔ Kivy (قدیمی)

نسخهٔ اولیه با Python + Kivy نوشته شد و برای بیلد به Buildozer روی لینوکس نیاز دارد؛ روی ویندوز مستقیم بیلد نمی‌شود.

```bash
# روی لینوکس یا WSL2
pip install "buildozer==1.5.0" "cython<3"
buildozer -v android debug
```

پیش از بیلد، فونت فارسی لازم است (وگرنه متن‌ها مربع می‌شوند):

```bash
python scripts/fetch_font.py
```

محدودیت‌های این نسخه: ورودی متن فارسی در `TextInput` درست شکل نمی‌گیرد، فایل CSV در فضای خصوصی اپ می‌ماند، و زنجیرهٔ ساخت آن در ۲۰۲۶ شکننده است. به همین دلیل نسخهٔ وب جای آن را گرفته است.
